# Memoria de Hito 1

## 1) Propósito del hito

Establecer la base documental del proyecto para iniciar el desarrollo con alcance controlado, trazabilidad y criterios de evaluación defendibles.

## 2) Requisitos del hito identificados

## Fuentes revisadas

1. Repositorio del proyecto: <https://github.com/aaronblanco/cc-turnos-cprl>
2. Enunciado de trabajo recibido para esta fase (documentación inicial y restricciones de no implementación).
3. Arquitectura de referencia de microfrontends (Junta de Andalucía):
   - <https://desarrollo.juntadeandalucia.es/recursos/reglas-pautas/arquitectura-referencia-microfrontend>
   - <https://desarrollo.juntadeandalucia.es/recursos/reglas-pautas/norma-para-el-desarrollo-microfrontends>

## Requisitos consolidados para Hito 1

R1. Crear únicamente documentación en Markdown (sin código de aplicación ni infraestructura).

R2. Definir problema, objetivos, requisitos y alcance del MVP.

R3. Proponer arquitectura y flujos principales distinguiendo claramente diseño futuro vs implementación inexistente.

R4. Documentar decisiones arquitectónicas, alternativas y pendientes.

R5. Definir seguridad/autenticación de roles internos y tratamiento de pantalla pública.

R6. Establecer criterios de interfaz/accesibilidad y alineación con referencia de microfrontends.

R7. Planificar evolución por hitos y preparar checklist práctico de ejecución manual.

R8. No declarar cumplimientos sin evidencia ni inventar resultados.

## 5) Aspectos pendientes para cerrar el hito

1. Confirmar si existe rúbrica oficial adicional de Hito 1 fuera del contenido actual del repositorio.
2. Verificar manualmente el contenido completo de la documentación externa de microfrontends si hay restricciones de acceso.
